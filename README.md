# 校园失物招领

> 软件工程结对作业 · 第二次（代码实现） · 罗炜 102401317 / 罗堉楠 102401218

一个纯前端的「校园失物招领」Web 应用：让同学集中发布、浏览、搜索校园里的寻物与招领信息，找回或归还后由发布者把信息标记为「已找到 / 已归还」，减少重复询问和无效联系。

- 第一次作业（原型设计）仓库：https://github.com/power819/campus-lost-found
- 本次作业（代码实现）仓库：https://github.com/power819/102401317-102401218

---

## 一、功能列表

| 功能 | 说明 |
| --- | --- |
| 发布寻物 / 招领 | 填写物品名称、类别、地点、时间、描述、联系方式，必填项校验 |
| 集中浏览 | 首页按「全部 / 招领 / 寻物」类型 + 「7 大类别」筛选浏览 |
| 关键词搜索 | 按名称、类别、地点、描述模糊搜索，支持搜索历史、热门搜索 |
| 查看详情 | 查看完整描述、地点、时间、状态、发布者信息 |
| 联系发布者 | 弹窗展示联系方式，支持**一键复制** |
| 更新状态 | 发布者把信息标记为「已找到 / 已归还」，状态全局实时刷新 |
| 我的发布 | 集中管理自己发布的信息，含累计/进行中/已完成统计 |

> 按作业要求，**不实现**复杂后台、实名认证、即时聊天、地图定位。

## 二、技术栈

- 纯原生 **HTML + CSS + JavaScript**，零框架、零构建、零后端
- 数据用浏览器 **localStorage** 持久化（发布的内容刷新页面后仍在）
- 单元测试用 **Mocha + Node 内置 assert**（仅本地运行，不上传 GitHub）

## 三、目录结构

```
102401317-102401218/
├── index.html          # 入口页面（5 个页面 + 底部导航 + 弹窗）
├── css/
│   └── style.css       # 全部样式（蓝灰配色，主色 #2563EB）

│   ├── core.js         # 核心纯逻辑：搜索/筛选/状态机/校验/格式化（可被 Node require 做测试）
│   ├── data.js         # 8 条内置样例数据（首次打开时种子数据）
│   ├── store.js        # localStorage 读写封装（数据的增删改查）
│   ├── render.js       # DOM 渲染层（列表/详情/弹窗/提示，含 HTML 转义防 XSS）
│   └── app.js          # 应用入口：状态管理、事件绑定、页面路由、交互编排
├── docs/
│   └── 数据流图.md      # 关键流程与数据流图（Mermaid）
└── README.md           # 本文件：目录说明 + 使用说明
```

**分层设计**：`core.js`（业务规则，无 DOM）→ `store.js`（数据持久化）→ `render.js`（界面）→ `app.js`（编排）。核心逻辑与界面分离，因此 `core.js` 既能被浏览器加载，也能被 Node 直接 `require` 做单元测试。

> 注：`test/` 目录为单元测试，按作业要求「单元测试不必上传」，故未包含在仓库中，测试代码见博客。

## 四、使用说明（测试人员请看这里）

**运行方式（零依赖）**：

1. 下载 / `git clone` 本仓库的所有文件到本地；
2. 用**谷歌浏览器（Chrome）**双击打开 `index.html`（或右键 → 打开方式 → Chrome）；
3. 即可看到「校园失物招领」界面，无需安装任何环境、无需联网、无需后端。

> 本应用使用 localStorage 存数据，直接双击 `index.html` 即可完整运行，不依赖服务器。

**核心操作路径**：

1. **浏览 / 搜索**：首页看到信息列表，顶部搜索框输入关键词（如「保温杯」「图书馆」）回车或实时过滤；也可用「全部 / 招领 / 寻物」和类别 chips 筛选。
2. **查看详情 → 联系**：点任意卡片进入详情页，点「📞 联系发布者」弹窗展示联系方式，点「📋 复制联系方式」一键复制。
3. **发布**：点底部「➕ 发布」或首页「去发布」，选「发布招领 / 发布寻物」，填名称、地点、联系方式（带 `*` 为必填）后点「发布信息」，成功后自动回首页并置顶。
4. **更新状态**：在详情页或「我的发布」里点「✅ 标记已归还 / 已找到」，状态变为已完成，其他页面同步刷新。
5. **我的发布**：底部「👤 我的」查看自己发布的全部信息及统计。

## 五、数据说明

- 首次打开时自动写入 8 条样例数据（模拟校园里已有的信息）；
- 之后发布、修改状态都会实时写入 localStorage，刷新不丢失；
- 想恢复初始数据，可在浏览器控制台执行 `localStorage.removeItem('campus-lost-found-items-v1')` 后刷新页面。
